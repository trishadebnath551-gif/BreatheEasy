🌿 BreatheEasy – Air Quality & Weather Monitoring

BreatheEasy is a web application designed to help users monitor air quality and weather conditions in their selected location.

✨ Features

- Real-time Air Quality Index (AQI)
- PM2.5 and PM10 monitoring
- Weather information including temperature, humidity and wind speed
- City search with autocomplete
- Current location detection
- Hourly air quality forecast
- Health recommendations based on air quality

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Open-Meteo APIs

🌐 API Sources

- Open-Meteo Air Quality API
- Open-Meteo Weather API
- Open-Meteo Geocoding API

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using Live Server.

👩‍💻 Project Purpose

Created as a beginner-friendly portfolio project to explore frontend web development, API integration and environmental awareness.
